ATLAS GALÁCTICO — INSTALACIÓN EN APACHE
========================================

Contenido
---------

La carpeta "atlas-galactico" contiene la web completa y lista para servir.
No requiere Node.js, npm, base de datos ni proceso de compilación.

Instalación rápida
------------------

1. Copia la carpeta "atlas-galactico" dentro del DocumentRoot de Apache.

   Ejemplo habitual en Debian/Ubuntu:
   /var/www/html/atlas-galactico/

2. Comprueba que Apache puede leer la carpeta y todos sus ficheros.

3. Abre esta dirección en el navegador:
   http://localhost/atlas-galactico/

Si usas un host virtual, puedes señalar DocumentRoot directamente a la carpeta
"atlas-galactico" y abrir el nombre de host que hayas configurado.

Configuración de .htaccess
--------------------------

El fichero .htaccess desactiva el listado de directorios, declara los tipos de
los datos y añade cabeceras de seguridad. Para aplicarlo, la configuración del
directorio debe permitir al menos:

AllowOverride FileInfo Options

Si tu servidor usa "AllowOverride None", Apache ignorará .htaccess y la web
seguirá funcionando; puedes trasladar esas directivas a la configuración del
host virtual o retirar el fichero si tu política no permite Overrides.

Funcionamiento sin Internet
---------------------------

El mapa, la búsqueda, las fichas locales, las hiperrutas y la descarga CSV se
sirven íntegramente desde este paquete. La vista previa de Wookieepedia necesita
acceso a Internet desde el navegador del visitante para consultar
https://starwars.fandom.com. Si no hay conexión, el resto de la web continúa
operativo y el modal muestra un aviso.

Privacidad de navegación
------------------------

La interfaz no contiene botones ni enlaces que abran páginas externas. La
información de Wookieepedia aparece únicamente dentro del modal del visor.
