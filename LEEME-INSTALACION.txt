ATLAS GALÁCTICO — INSTALACIÓN LOCAL EN WINDOWS / XAMPP
=======================================================

Esta carpeta contiene la web completa lista para Apache.
No necesitas instalar Node.js, Python, Yarn ni ejecutar ningún comando.

SI YA TIENES EL ENLACE DE CARPETAS CREADO
-----------------------------------------

Tu configuración es:

  Carpeta real:       E:\gits\MapaEspacial
  Acceso desde XAMPP: E:\Xampp\htdocs\MapaEspacial

1. Haz una copia de seguridad de E:\gits\MapaEspacial si quieres conservar
   la versión anterior.
2. Extrae el ZIP dentro de E:\gits y permite que Windows combine la carpeta
   MapaEspacial y sustituya los archivos existentes.
3. Arranca Apache desde el panel de XAMPP.
4. Abre en el navegador:

   http://localhost/MapaEspacial/

El enlace de carpetas es permanente: no tienes que volver a ejecutar mklink.

SI NO UTILIZAS EL ENLACE DE CARPETAS
------------------------------------

1. Extrae la carpeta MapaEspacial directamente dentro de:

   E:\Xampp\htdocs\

2. Arranca Apache desde XAMPP.
3. Abre:

   http://localhost/MapaEspacial/

IMPORTANTE
----------

- No abras index.html con doble clic. La web debe servirse mediante Apache
  porque carga el catálogo mediante peticiones locales.
- Si Apache ya estaba abierto durante la actualización, normalmente no hace
  falta reiniciarlo. Pulsa Ctrl+F5 en el navegador para evitar que se muestre
  una copia antigua guardada en caché.
- El catálogo CSV está incluido en data\galactic-locations.csv.
- Las capas Cuadrícula, Regiones e Hiperrutas están preparadas por separado,
  aunque provisionalmente utilizan la misma imagen completa del mapa.
